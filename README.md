# Spell FX Free

**6 animated spell effects as PNG sprite sheets, free, for any engine.** Each comes in three sets:
256 px and 128 px HD, and pixel art drawn at 64 px, not shrunk.

### Want more?

**[Spell FX](https://heyheythere.itch.io/spell-fx)** has 56: storm, holy, shadow and poison on top
of these three, and casts, novas, pillars, ground areas, auras and magic circles in every element.
Same sheets, same player.

### What's inside

- **fire**, **ice** and **arcane**, each a **bolt** (a looping projectile) and the **impact**
  where it hits.
- Transparent PNG sheets, 8 frames a row, plus an `effects.json` with every frame size, frame
  count, fps and anchor, and a GIF preview of each.
- **Godot 4 player included:** `SpellFX.fly(self, "fire", from, to)` sends a bolt that bursts
  where it lands. Import steps for Unity and GameMaker in the README.

### Compatibility

- **Any engine** that plays sprite sheets: Unity, GameMaker, Godot, Defold, Construct, Phaser,
  LÖVE, MonoGame.
- The Godot player: Godot **4.3 to 4.7**, tested on both ends and on every renderer.
